# Чек-лист релиза VK Mini Apps

Приложение: **Бортник — золотые соты**

VK App ID: **_подставить после создания_**

Production: **_URL Timeweb_**

## 1. Код и сборка — обязательно

- [ ] В рабочей ветке нет случайных файлов, токенов и секретов.
- [ ] Установлена поддерживаемая версия Node.js.
- [ ] `pnpm install --frozen-lockfile` проходит с чистого окружения.
- [ ] `pnpm run typecheck` проходит без ошибок.
- [ ] `pnpm run lint` проходит без ошибок.
- [ ] `pnpm run test:all` проходит без ошибок.
- [ ] `pnpm run timeweb:build` создаёт `out/index.html`.
- [ ] Созданы `out/privacy/index.html` и `out/terms/index.html`.
- [ ] В консоли браузера нет необработанных ошибок.
- [ ] В production не загружаются скрипты или шрифты с заблокированных в РФ CDN.
- [ ] В клиентскую сборку не попали секретный ключ VK и служебные токены.

## 2. Основной игровой сценарий — обязательно

- [ ] Новый пользователь видит экран «Бортник» и кнопку «В улей».
- [ ] Соседние соты меняются местами; невалидный свап откатывается.
- [ ] Матч из трёх очищает клетки и наполняет банку мёда.
- [ ] Матч из четырёх / пяти создаёт спецфишку.
- [ ] Ходы списываются; при нуле ходов показывается поражение.
- [ ] Победа открывает следующую лужайку и награду.
- [ ] Прогресс сохраняется после обновления страницы.
- [ ] Сброс прогресса создаёт новую игру.
- [ ] Сворачивание приложения ставит игру на паузу.

## 3. Мета и монетизация

- [ ] Улучшения пасеки списывают кристаллы и влияют на уровни.
- [ ] Ежедневные задания засчитываются и выдают награду один раз.
- [ ] Rewarded ads начисляют монеты/ходы только после успешного просмотра.
- [ ] Interstitial ограничен по частоте.

## 4. Каталог VK

- [ ] Заполнены тексты из `moderation/texts.txt`.
- [ ] `pnpm run moderation:assets` и `moderation:validate` проходят.
- [ ] Загружены иконки, сниппет и скриншоты.
- [ ] Указаны URL privacy/terms.
